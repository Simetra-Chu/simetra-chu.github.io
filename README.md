# ExamRank HTML

Website: https://simetra-chu.github.io/examrank.html

Website introduction briefly explains the purpose and two-step percentile → grade workflow. Both introduction and model notes open in the same accessible scrollable overlay without leaving the page or clearing inputs; detailed input examples are expandable in model notes. Missing grade distributions receive targeted amber guidance; visitors may explicitly choose a clearly labelled reference-distribution scenario, rescaled to each assessment maximum. Actual errors use higher contrast coral-red styling. No missing future distribution is silently invented.

One self-contained HTML combines exam percentile/rank estimation and conditional course grade scenarios. Save examrank.html to calculate offline. Styles, scripts and calculation workers are embedded; calculation needs no API or external CDN. Optional feedback is saved privately using a dedicated intake service. Contacts are optional, and exam inputs are sent with feedback only when the visitor explicitly opts in.

Use the two-step workflow: first estimate an exam percentile/rank. A usable percentile result automatically reveals course grade prediction below it, with the known exam data carried over. Missing-information or scenario-only outputs do not unlock the second step. Changing or clearing the exam inputs hides the grade step and invalidates old grade results. Grade settings include editable assessment weights, custom items such as attendance/assignment, and adjustable latent correlation (default 0.5). Four exclusive bands cover all outcomes: A top20%, A−20–40%, B+40–60%, and below B+ (outside the top60%, the remaining probability). Predictions depend on the supplied course statistics and assumptions.

The primary estimate prefers linear interpolation strictly between published quantiles, with Beta as a separate comparison. Identified Beta extrapolation is labelled. Ties, exact anchors, boundaries or missing data may prevent a unique estimate. Support/rounding ranges are not confidence intervals; internal holdout checks do not prove actual rank accuracy. See [Tutorial](https://simetra-chu.github.io/tutorial.html) and [Model notes](https://simetra-chu.github.io/model.html).

This public repository contains only the built website, public feedback URL/publishable application key, and landing page. It contains no server secret or feedback records. Source repositories are maintained privately. Third-party license notices are retained in the embedded calculation bundles. Existing https://simetra-chu.github.io/examrank/ pages remain available as a legacy release.
