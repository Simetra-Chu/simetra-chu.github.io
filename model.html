先看本次使用的方法

结果区直接显示“本次采用的方法”。当个人成绩严格处于相邻已知分位点之间时，优先使用分位数线性插值；Beta拟合若可用，会作为单独对照显示。两种估计从不平均。超出已知分位点范围的Beta结果会明确标注为外推。

当统计量不能稳定识别分布，或同分及端点使唯一位置无法确定时，页面会给出限制和支持范围，保留空白而不制造精确名次。只有均值时无法确定唯一分布；浓度κ情景是用户指定的假设。

线性插值：从成绩找百分位

已知相邻门槛q₁、q₂分别对应p₁、p₂，且q₁ < x < q₂时，局部估计为：

p(x) = p₁ + (x − q₁) / (q₂ − q₁) × (p₂ − p₁)

这假设两点之间“分数变化与百分位变化近似线性”。它只使用局部已知点，不能说明所有可能的真实分布。支持范围[p₁, p₂]来自摘要约束，不是95%置信区间，也不是已经测出的统计覆盖概率。

若q₁ = q₂，分母为0，不能这样反解；若个人成绩恰好等于门槛，公布分位点与四舍五入也不足以揭示同分组内的个人位置。0分和满分也可能存在大量同分，连续分布端点不能替代学校的排名规则。

和课堂上的πₚ有什么关系？

课堂常记πₚ为第p分位数：给定百分位p，求成绩πₚ。相邻点之间的线性写法是：

πₚ = q₁ + (p − p₁) / (p₂ − p₁) × (q₂ − q₁)

本网站当前的局部插值则给定成绩x，反求百分位p。两式在严格递增的同一段内互为反解。课堂若从原始样本计算分位数，还可能有不同的排序位置和插值约定；本站接收的是老师已经公布的分位点，不能还原原始样本。

例如P60 = 85.5、P80 = 90：课堂给p = 0.70可求π₀.₇ = 87.75；本站给x = 87.75则反求p = 0.70。

Beta拟合：一个有界连续近似

先把成绩除以满分，放在0到1的区间，再用Beta分布近似全班成绩。均值和方差可能通过矩估计确定参数；中位数、多个分位点或其他摘要则需要数值拟合。α、β描述分布形状，不是置信度。

同一组少量摘要可能对应许多真实分布。Beta的形状限制不一定适合双峰、长尾、满分堆积或大量同分的班级。特别是超出已知门槛的外推，更依赖模型假设。Beta和插值的分歧是敏感性诊断，不能靠取平均来消除。

PCHIP尚未投入使用。它是未来可评估的保形分段三次插值候选；曲线更平滑本身不等于真实排名更准确，需要在独立真实数据上检验。

三类“正确”必须分开理解

  • 数值正确性：公式、程序、优化和随机抽样是否正确实现。收敛或抽样次数增加不证明模型符合真实班级。
  • 摘要拟合程度：模型与已公布均值、分位点是否接近。可选留一检查最多留出6个内部分位点，按相同可用折比较插值与Beta的百分位误差；留出点不能继续用于训练。它检验稀疏摘要一致性。
  • 真实排名准确性：需要独立的真实成绩、个人实际位置与同分规则才能验证。仅有摘要无法完成这一步。

公布精度敏感性仅描述摘要四舍五入对稳定局部括号的影响。无论它、支持范围还是模拟抽样误差，都不能自动当作实际排名的95%置信区间。

等级预测是条件情景

等级模块保留已取得的个人成绩，按你提供的各项分布、权重及相关性假设，模拟未知成绩与最终名次。相关性ρ、未来考试分布、同分规则和名额取整改变时，结果也会变化。未来分布未知时，填写的是明确假设，不是已经观测到的数据。

增加模拟次数只能降低部分数值抽样误差，不能补上缺失的全班数据或消除模型偏差。实际等级和排名以学校公布为准。
